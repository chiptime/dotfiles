# Mission kickoff

Run the **Mission Contract** from your global instructions for this mission, strictly:

1. Explore the code and the current state first; do not ask what you can discover.
2. If real scope or product decisions remain, ask them ALL now in one numbered message, each with a recommended default, then stop and wait for that single answer.
3. Write the Mission Brief (Goal, Scope in/out, Done when, Authorized actions, Hard stops).
4. Execute until "Done when" is verified. Do not ask for permission to continue; pause only on a hard stop, and only after finishing every other unblocked item.
5. Close with the final report: status per item, evidence, decisions taken, open blockers.
